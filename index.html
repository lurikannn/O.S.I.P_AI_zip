01 / О системе

Что такое
OSIP_AI?

По исходному файлу это All-in-One клиент-агент и сервер лицензий в одном Python-файле. При запуске сервер поднимается в фоне, затем стартует клиент.

v8

OSIP CODE AGENT
Система построена вокруг агентского подхода: сначала анализировать проект, затем точечно менять его и после изменений запускать проверки. Рабочая директория — ~/OSIP_WORKSPACE.

05 / Скачать и запуск

Запусти OSIP
на своём ПК.

Исходник прямо указывает команду запуска: python osip_all.py. Для работы нужны Python, Flask и Requests.

pip install flask requests
python osip_all.py

Инструкция
1. Python
Установи Python и запусти терминал в папке проекта.
2. Зависимости
Выполни pip install flask requests.
3. API Key
Для подключения AI требуется настроенный ключ доступа формата sk-....
4. Запуск
Выполни python osip_all.py. Локальный сервер лицензий поднимется автоматически.
5. Рабочая папка
Агент использует OSIP_WORKSPACE в домашней директории пользователя.
